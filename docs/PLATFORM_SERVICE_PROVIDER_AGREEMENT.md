## 第一条 定义

1. “平台”指甲方运营和管理的服务撮合、订单管理、结算管理相关系统、网站、小程序、H5 页面、后台管理系统及其配套服务。
2. “用户”指通过平台提出服务需求、下单或由平台协助登记订单的自然人或其他主体。
3. “服务者”指乙方及其他经平台审核通过后入驻的独立服务提供方。
4. “订单”指用户通过平台下单或由平台根据用户需求登记形成的服务记录，包括服务项目、金额、服务者、订单状态、结算金额等信息。
5. “服务收益”指乙方基于其实际完成的平台订单，在扣除依法依规及平台规则约定的费用、保证金、处罚、退款、设备租赁、线下管理费用或其他应扣款项后，可申请结算的金额。
6. “冻结期”指订单完成后，为处理订单争议、退款、服务异常、风控核验、账务核对等事项，平台按照公示规则对相应服务收益暂缓转为可提现金额的期间。

## 第二条 入驻身份与合作关系

1. 乙方自愿以独立服务提供方身份入驻平台，自主决定是否承接平台撮合或登记的订单。
2. 双方确认，本协议不构成劳动合同、劳务派遣关系、雇佣关系、代理关系、合伙关系或任何形式的人身从属性管理关系。
3. 甲方不向乙方支付工资、薪资、固定报酬、社保、公积金、员工福利或劳动法项下的用工待遇。乙方通过平台订单取得的款项，为其基于独立提供服务形成的服务收益或合作结算款。
4. 乙方应自行判断其是否具备提供相应服务的能力、时间、设备和条件，并自行承担其服务过程中的必要成本和责任。
5. 甲方有权基于平台运营安全、用户体验、订单履约质量、账务风险、合规要求等原因，对乙方入驻资格、接单资格、结算资格或服务展示状态进行审核、限制、冻结、暂停或终止。

## 第三条 平台服务内容

甲方主要向乙方提供以下平台服务：

1. 服务者入驻信息登记、身份或联系方式核验；
2. 服务项目、服务范围、订单需求等信息展示或登记；
3. 用户订单撮合、订单创建、订单状态管理；
4. 服务完成后的结算计算、账务记录、冻结期管理；
5. 保证金、设备租赁费、线下费用、处罚、退款、异常订单等账务扣款记录；
6. 乙方提现申请受理、后台审核及转账处理；
7. 平台规则、服务规范、风控提示、账务明细查询等辅助服务。

## 第四条 服务提供与订单管理

1. 乙方应按照订单约定、平台公示规则及用户合理需求提供服务，并保证服务过程真实、合法、合规。
2. 乙方不得通过虚假接单、虚假服务、刷单、诱导交易、私下绕开平台结算、恶意退款、冒用他人身份、侵犯用户权益等方式损害用户、平台或其他服务者利益。
3. 订单完成后，平台可根据订单状态、服务结果、用户反馈、售后或争议情况，对订单是否进入结算进行核验。
4. 如订单发生取消、退款、投诉、服务异常、风控命中、资金异常、违规处罚等情形，甲方有权按照平台规则调整乙方对应服务收益、冻结状态或扣款金额。

## 第五条 服务收益结算规则

1. 乙方服务收益以平台系统记录为主要依据，包括订单金额、结算金额、服务者分配、分红规则、扣款规则、账户余额等信息。
2. 订单完成并通过平台结算核验后，对应服务收益将先进入冻结期。冻结期届满且无争议、退款、处罚、欠款或其他限制情形的，相关金额可转为乙方可申请提现的余额。
3. 乙方理解并同意，冻结期并非平台占有乙方资金收益的目的，而是用于订单争议处理、用户售后保障、账务核验、风控安全及平台规则执行。
4. 乙方申请提现前，平台有权核验乙方账户是否存在未结清款项，包括但不限于保证金差额、设备租赁费用、线下费用、罚单、退款冲正、异常订单扣款、已发起提现冻结金额等。
5. 如乙方账户存在应扣未扣、欠款、负余额、未结清账单或其他风险事项，甲方有权依据平台规则暂缓提现、优先冲抵欠款、要求乙方补足保证金或完成账单缴费。
6. 乙方提现申请经平台后台审核通过后，甲方将根据当时可用的转账方式完成结算处理。转账方式包括但不限于人工线下打款、微信/支付宝/银行或其他合规支付通道；具体以平台实际开放能力为准。
7. 因乙方提供的收款账户、二维码、实名信息、联系方式、微信授权信息不准确或不可用导致转账失败、延迟或退回的，由乙方自行承担相应影响，甲方可要求乙方重新提交有效信息后再处理。

## 第六条 保证金及费用扣缴

1. 为保障订单履约、用户权益、设备或平台规则执行，甲方可根据平台公示配置要求乙方缴纳或通过结算抵扣方式形成保证金。
2. 乙方存在保证金未达到平台规则要求、设备租赁费未缴清、线下费用未缴清、罚单未处理、退款冲正未结清等情况的，甲方有权从乙方可结算余额中优先扣除相应款项。
3. 如乙方可用余额不足以完全冲抵应扣款项，甲方不会因系统扣款将乙方余额无依据地扩大为异常负数，但乙方仍应按照平台规则补足应承担的费用或欠款。
4. 乙方退出平台时，保证金退还或不退还规则以乙方入驻时适用的平台规则、实际入驻时长、有效订单量、违规情况、保证金缴纳或抵扣完成情况等为依据。

## 第七条 提现授权与收款信息

1. 乙方申请提现时，应确认提现金额、收款方式、收款账户或收款二维码真实有效，并授权甲方或甲方合作支付机构根据审核结果向乙方指定账户转账。
2. 如乙方通过微信网页授权、小程序授权或其他方式绑定收款身份，乙方同意平台在必要范围内获取并保存与收款身份识别相关的信息，包括 openid、unionid、绑定时间、AppID、授权平台类型等。
3. 前述授权信息仅用于账户识别、会员/服务者身份绑定、提现审核、结算转账、风控核验及争议处理，不用于与本协议无关的用途。
4. 如支付通道、商户规则、监管要求或风控策略发生变化，甲方有权调整提现方式、到账时间、审核规则或单笔/单日额度，并通过平台公告、系统提示或其他合理方式告知乙方。

## 第八条 税费与合规责任

1. 双方确认，乙方通过平台取得的服务收益，不属于甲方向乙方支付的工资或固定薪酬。
2. 乙方应根据国家法律法规及个人实际收入情况，自行履行纳税申报、税款缴纳及其他法定义务。
3. 如法律法规、税务机关、监管机构或支付机构要求甲方履行信息报送、协助申报、代扣代缴、资料留存或风险核验义务，乙方应予以配合，并提供真实、准确、完整的身份、订单、收款及税务相关资料。
4. 因乙方拒绝提供资料、提供虚假资料、隐瞒收入、违规交易或其他个人原因导致的税务、行政、民事或刑事责任，由乙方依法自行承担。

## 第九条 数据留存与资料真实性

1. 乙方应保证其提交的姓名、身份证件、联系方式、微信授权、收款账户、服务资料及其他入驻信息真实、准确、完整、合法。
2. 甲方有权根据业务管理、支付机构审核、监管要求、争议处理和财务对账需要，留存乙方入驻资料、订单记录、结算记录、提现记录、操作日志、授权记录及沟通记录。
3. 如乙方资料发生变更，应及时在平台更新或通知甲方。因乙方资料未及时更新导致的结算失败、权益受损或责任争议，由乙方自行承担。

## 第十条 违规处理

乙方出现以下情形之一的，甲方有权采取限制接单、冻结账户、暂停结算、扣除保证金、取消入驻资格、追偿损失、移交相关机关等措施：

1. 提供虚假身份、虚假收款信息或冒用他人账号；
2. 虚假接单、刷单、恶意退款、恶意投诉或制造异常订单；
3. 绕开平台私下交易，损害用户、平台或其他服务者利益；
4. 拒不处理订单争议、售后、退款、罚单、账单或欠款；
5. 违反法律法规、公序良俗、平台规则或支付机构规则；
6. 其他足以影响平台交易安全、资金安全、用户权益或平台声誉的行为。

## 第十一条 协议变更与退出

1. 甲方可根据业务发展、监管要求、支付通道规则、风控要求或平台运营需要，对平台规则、本协议相关条款、结算周期、冻结期、提现方式、保证金规则等进行合理调整。
2. 乙方如不同意调整内容，可停止承接新订单并按照平台退出流程申请退出；乙方继续使用平台或承接订单的，视为接受调整后的规则。
3. 乙方申请退出平台时，应先完成未结订单、售后争议、保证金处理、设备归还、欠款冲抵、费用缴纳等事项。平台将按照当时有效规则处理乙方可结算余额和保证金。
4. 乙方退出平台不影响其在入驻期间已经产生的订单责任、售后责任、费用扣缴、税务义务、保密义务及争议处理责任。

## 第十二条 争议解决

1. 双方因本协议产生争议的，应先友好协商解决。
2. 协商不成的，任一方可向甲方所在地有管辖权的人民法院提起诉讼。
3. 本协议未尽事宜，双方可另行签署补充协议；补充协议与本协议具有同等法律效力。

## 第十三条 其他

1. 本协议自乙方在线确认、签字确认或实际使用平台承接订单之日起生效。
2. 本协议可采用纸质签署、电子签署、平台勾选确认、短信/微信确认、后台操作确认等方式订立。依法有效的电子数据、操作日志、授权记录、订单记录、结算记录可作为协议履行及争议处理依据。
3. 本协议一式两份，甲乙双方各执一份；电子版本与纸质版本具有同等效力。
