# 收钱吧上线检查清单

## 1. 发布前

- 备份生产数据库。
- 确认镜像包含以下迁移：
  - `20261010143000_prepare_shouqianba_unpaid_liability`
  - `20261013150000_add_order_payment_preselection`
  - `20261013173000_add_order_draft_payment_status`
- 先在生产环境配置下列变量，再激活终端：
  - `SHOUQIANBA_VENDOR_SN`
  - `SHOUQIANBA_VENDOR_KEY`
  - `SHOUQIANBA_APP_ID`
  - `SHOUQIANBA_DEVICE_ID`（生产环境使用固定且唯一的值）
  - `SHOUQIANBA_NOTIFY_URL=https://api.lmsdclub.cn/shouqianba/notify`
  - `SHOUQIANBA_CREDENTIAL_ENCRYPTION_KEY`（独立强随机密钥，不得与 vendor key 相同）
- `SHOUQIANBA_CREDENTIAL_ENCRYPTION_KEY` 会用于加密终端密钥。终端激活后不得随意更换，否则已入库的终端凭据无法解密。
- 确认服务端 `.env` 权限为 `600`，参数不出现在前端构建产物、日志或仓库中。

## 2. 发布顺序

1. 发布后端并执行 `prisma migrate deploy`。
2. 检查服务健康、迁移状态和收钱吧配置状态；此时不得反复调用激活接口。
3. 只使用一个固定 `device_id` 激活生产终端一次。激活成功后再次调用会被本地阻断，避免消耗激活码次数。
4. 执行一次签到，确认新终端密钥已加密入库。
5. 发布管理端，清理 CDN/浏览器旧资源缓存。

## 3. 生产冒烟测试

1. 用普通商品创建 `0.01` 元测试订单，确认付款小票金额、单号、到期时间和客服提示正确。
2. 扫码支付，确认订单从“待在线支付”自动进入“待派单/待接单”，不使用人工确认收款。
3. 有预选服务者时：
   - 全部空闲：自动派单，并保留续单/指定分红归因快照。
   - 任一非空闲：保持待派单，不得强制派单。
4. 暂时关闭浏览器等待支付，确认服务端主动查单仍能将支付状态回写。
5. 创建一个付款码但不支付，确认约 4 分钟后失效，最终收敛为失败/订单草稿，旧码不再展示为可支付。
6. 对 `0.01` 元订单发起原路退款，再用主动查单确认收钱吧返回 `REFUNDED`，同时核对订单、退款流水、收款方实际资金。
7. 检查回调日志不含 vendor key、terminal key 或完整请求签名。

## 4. 回退原则

- 上线后若生成付款码失败，先停止新的在线收款操作，不要反复激活终端。
- 保留数据库中的终端凭据与支付/退款流水；不通过删表或回滚数据解决支付对账问题。
- 已产生外部资金变动时，以收钱吧查单结果为准，再做本地幂等补偿。
